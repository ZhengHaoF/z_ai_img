# 2026-07-17 工作日志

## 图片编辑/生成页面修改

**问题**: 在编辑页面和生成页面，点击生成/编辑按钮时，已生成的图片会被清空（`images: const []`），导致用户体验不佳。

**修改方案**: 采用"旧图保留，新图追加"方案。

**修改文件**:
- `lib/providers/generate_provider.dart`
- `lib/providers/edit_provider.dart`

**修改内容**:
1. 删除 `generateImage` / `editImage` 方法中 `state.copyWith` 里的 `images: const []`
2. API 返回后将 `images: images` 改为 `images: state.images + images`，实现新图追加到旧图列表

**效果**: 用户多次点击生成/编辑时，历史结果会保留在列表中，新结果追加到末尾。
