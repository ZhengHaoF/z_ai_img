## 修复 z_ai_img 全部审查发现的 Bug

针对 2026-09-15 审查报告逐项修复，`flutter analyze` 通过（No issues found）。

### 高优先级
1. **macOS 沙盒网络权限**：DebugProfile.entitlements / Release.entitlements 增加 `com.apple.security.network.client`。
2. **托盘图标资源**：新增 `tool/generate_tray_icons.py`（Pillow 生成），产出 `assets/icons/tray_{idle,loading,completed,error}.png`（32x32，macOS/Linux）和 `.ico`（16~256 多尺寸，Windows）。`lib/utils/system_tray.dart` 按 `Platform.isWindows ? ico : png` 选择扩展名，并补 `dart:io` import。
3. **Android 前台服务幽灵通知**：`GenerateForegroundService.onStartCommand` 返回值 `START_STICKY` → `START_NOT_STICKY`，并处理 null intent（直接停止）。
4. **clearAll 清除不干净**：`SettingsNotifier.clearAll` 补删 `isDarkMode` / `showTrayIcon` 持久化键。

### 中优先级
5. **缓存层**：`ImageRepository.clearCache` 改为 async 并清磁盘；`_addToCache` 中 `_imageStorage.save` 用 `unawaited(...then<void>...catchError)` 防 unhandled；`ImageStorage._evictOldest` 优化为 O(n log n)（先统计总大小再删）。
6. **网络日志并发串号**：`BaseHttpClient` 用自增 `_requestSeq` 写 `options.extra['request_id']`，耗时统计按 ID 取，不再以 URL 为 key。
7. **HomePage 切换动画**：新增 `FadeIndexedStack`（TickerProviderStateMixin + FadeTransition + IndexedStack），替代 AnimatedSwitcher 无 key 失效问题。
8. **编辑页状态**：`clearSourceImages` 同时清空遮罩；`clearMaskImage` 保留 error。
9. **未使用依赖**：移除 pubspec 中 `workmanager` / `window_manager`（零引用），AndroidManifest 删除 `RECEIVE_BOOT_COMPLETED` / `WAKE_LOCK` 多余权限。
10. **Android 保存图片权限**：Manifest `WRITE_EXTERNAL_STORAGE` maxSdkVersion 28→29，加 `requestLegacyExternalStorage="true"`；`image_utils.dart` 改用 `Gal.hasAccess/requestAccess(toAlbum:true)`，移除 permission_handler 依赖。

## 平台收敛：仅支持 Android + Windows

用户要求移除 iOS 支持，顺带收敛为 **Android + Windows** 双平台（同时移除 macOS / Linux）。

### 代码改动
- `lib/core/platform/platform_capabilities.dart`：删除 `isMacOS` / `isLinux` / `isIOS`，`isDesktop => Platform.isWindows`，`isMobile => Platform.isAndroid`，`supportsForegroundService => Platform.isAndroid`
- `lib/core/platform/foreground_service_impl.dart`：isSupported 仅 Android
- `lib/core/platform/system_tray_impl.dart`：isSupported 仅 Windows
- `lib/utils/image_utils.dart`：保存相册仅 Android，移除 iOS 分支，注释更新
- `lib/utils/system_tray.dart`：仅保留 .ico 路径，移除 png 分支和 `dart:io` import

### 资源/配置
- 删除 `ios/`、`macos/`、`linux/` 三个平台目录
- `assets/icons/` 精简为 4 个 `.ico`（删除 png）
- `tool/generate_tray_icons.py` 只生成 ico
- `pubspec.yaml`：移除 iOS 版本说明、托盘注释改为 Windows
- `analysis_options.yaml`：exclude 仅保留 build/android/windows
- `.metadata`：移除 ios/linux/macos 平台记录
- 文档：README.md / README_EN.md / CODE_WIKI.md / 设计方案.md / 重制方案.md 同步更新

### 注意
- `flutter pub get` 会自动把 ios/web/macos/linux 加回 analysis_options exclude，需手动再删。
- pubspec.lock 中 file_selector_linux / image_picker_ios 等是插件传递依赖，无法手动移除，无害。
