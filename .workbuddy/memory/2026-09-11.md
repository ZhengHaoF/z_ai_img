## 三件事：修磁盘缓存 + 彻底去掉 Web + 对齐 README 目录树（已完成）

### 1. 修复磁盘缓存（#1）
- `lib/providers/settings_provider.dart`：`imageStorageProvider` 默认实现由 `ImageStorage(Directory(''))` 改为 `throw UnimplementedError`（与 `sharedPreferencesProvider` 一致），并移除因此失效的 `dart:io` 导入。
- `lib/core/bootstrap.dart`：新增 `_resolveImageCacheDirectory()`，用 `getApplicationSupportDirectory()/image_cache` 作为缓存目录（无 path_provider 环境回退到 `Directory.systemTemp/z_ai_image_cache`），在 `ProviderScope.overrides` 中注入 `imageStorageProvider`。
- `lib/core/storage/image_storage.dart`：`save()` 增加父目录兜底创建（`create(recursive: true)`），避免目录不存在时静默失败。
- **重要遗留发现（未修，需决策）**：磁盘缓存目前是「只写不读」——`ImageStorage.load()/clear()` 与 `ImageRepository.clearCache()` 全项目无任何调用点。修好目录后 `save()` 会正常写盘（上限 500MB LRU），但没有读取方。要真正让磁盘缓存产生价值，需二选一：**(a)** 接上读取路径（≈「历史记录」功能，需要 UI，属未来扩展）；**(b)** 直接删掉文件缓存层，只保留内存 LRU。

### 2. 彻底移除 Web 平台
- 删除 `web/` 整个目录（7 个文件）；`.metadata` 移除 `platform: web` 条目。
- 合并 `lib/utils/image_utils_nonweb.dart` 进 `lib/utils/image_utils.dart` 并删除前者（`platformSaveImage` → 私有 `_saveImageToGallery`）。
- `lib/core/platform/platform_capabilities.dart` 重写：删除 `isWeb`、`supportsNotifications`、`supportsNativeShare`、`supportsFilePicker`（这些能力位本质只是「非 Web」的编码），保留 `isDesktop/isMobile/各 isXxx/supportsSystemTray/supportsForegroundService`。
- `lib/utils/foreground_service.dart`：移除 6 处 `if (!PlatformCapabilities.supportsNotifications) ...` 死分支及该导入。
- 其余 kIsWeb 清理：`foreground_service_impl.dart`、`system_tray_impl.dart`、`native_foreground_service.dart`、`providers/edit_provider.dart`（含 `maskImagePath` 常量化为 `'mask_local'`）。

### 3. 对齐 README 目录结构
- `README.md` / `README_EN.md` 的 `lib/` 目录树整体重写为与 `lib/` 实际文件**逐条一致**（用 comm 对比 basename 校验通过：无缺失、无多余）。

- 平台说明同步：README/README_EN/CODE_WIKI/设计方案 移除「Web 支持」行与 `flutter build web` 命令，改为「五端（iOS/Android/macOS/Windows/Linux）」并加注「已放弃 Web」。
