# 2026-07-29 工作日志

## 修复三个 Bug（ZHF 反馈）

### 1. 生成结果标题重复
- 根因：`generate_page.dart` / `edit_page.dart` 自建标题行 + `ResultGrid` 内部也有标题行，双重渲染
- 修复：给 `ResultGrid` 增加 `title` 参数（默认"生成结果"），页面层不再自建标题，统一由 ResultGrid 渲染
- 涉及文件：`result_grid.dart`、`generate_page.dart`、`edit_page.dart`

### 2. 清除按钮无效
- 根因：`_onClearPressed` 调用的是 `clearError()`（只清 error），没清 images
- 修复：两个 Notifier 各增加 `clearResults()` 方法，页面改为调用 `clearResults()`
- 涉及文件：`generate_provider.dart`、`edit_provider.dart`、`generate_page.dart`、`edit_page.dart`

### 3. 切后台请求失败
- 根因：`NativeForegroundService`（真正的 Android 前台服务）已写好但从未被调用；实际用的只是 `flutter_local_notifications` 发通知，无保活能力
- 修复：
  - 在 `GenerateNotifier.generateImage()` 和 `EditNotifier.editImage()` 中集成 `NativeForegroundService.start()/stop()`
  - 统一通知渠道 ID（`updateGeneratingNotification` 从 `generating_channel` 改为 `generating_channel_v2`）
  - AndroidManifest 权限从 `FOREGROUND_SERVICE_SPECIAL_USE` 改为 `FOREGROUND_SERVICE_DATA_SYNC`（与服务类型匹配）
  - Kotlin 侧 `startForeground` 在 API 34+ 显式传入 `FOREGROUND_SERVICE_TYPE_DATA_SYNC`
- 涉及文件：`generate_provider.dart`、`edit_provider.dart`、`foreground_service.dart`、`GenerateForegroundService.kt`、`AndroidManifest.xml`
