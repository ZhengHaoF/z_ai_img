# 2026-09-15

## 全项目代码审查（z_ai_img Flutter 应用）

对 lib/ 全部 53 个 Dart 文件 + Android 原生 Kotlin/Manifest + iOS/macOS 配置做了系统性 Bug 检查，`flutter analyze` 无静态问题。

主要发现：
- **高**：`assets/icons/` 目录为空，但 system_tray.dart 引用 4 个托盘图标，托盘功能运行时必然失败。
- **高**：`GenerateForegroundService.onStartCommand` 返回 `START_STICKY`，进程被系统杀死后会用 null intent 重启并显示"AI 任务进行中"幽灵通知；且 `ACTION_STOP` 分支是死代码（stop() 直接 stopService 不经过 onStartCommand）。
- **高**：`SettingsNotifier.clearAll()` 未移除 `isDarkMode` / `showTrayIcon` 持久化键，清除设置后重启仍会恢复旧值。
- **中**：`ImageRepository.clearCache()` 无调用点且只清内存不清磁盘；`_addToCache` 里 `_imageStorage.save()` 未 await，存在 unhandled async exception 风险。
- **中**：`ImageStorage._evictOldest` 每次删除后全目录遍历，O(n²)；`BaseHttpClient._requestTimestamps` 以 URL 为 key，并发同 URL 请求会串时间戳。
- **低**：HomePage AnimatedSwitcher+IndexedStack 无 key 导致切换动画失效；EditNotifier.clearMaskImage 会意外清空 error；清空源图后遮罩仍保留；workmanager/window_manager 依赖未使用但声明了多余 Android 权限。

未修改任何代码，仅审查。
